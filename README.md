# Craigslist Homepage Redesign
A modern redesign of the Craigslist homepage built for a design challenge.

[wilsskin.github.io/craigslist-homepage](https://wilsskin.github.io/craigslist-homepage)

---

## What It Does
- Reimagines Craigslist's dated homepage with a clean, scannable layout
- Allows users to select multiple locations with new modal design
- Preserves the full category taxonomy and search functionality

## How It's Built
React and TypeScript frontend built with Vite, styled with Tailwind CSS and shadcn/ui components. Category data is sourced from a local JSON taxonomy file. Deployed via GitHub Pages through a GitHub Actions workflow.

**Stack:** React, TypeScript, Tailwind CSS, shadcn/ui, Vite, GitHub Pages
